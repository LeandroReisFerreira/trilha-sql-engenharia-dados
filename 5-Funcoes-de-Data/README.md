# Módulo 05: Funções de Data

Neste módulo, aprendi a manipular dados cronológicos, realizar cálculos de intervalos de tempo e filtrar registros por períodos específicos.

### Conceitos Praticados:
- Extração de partes de uma data (Ano, Mês, Dia).
- Filtros por intervalos de datas e anos específicos (uso de `BETWEEN` com formatos de data).
- Cálculos de diferença entre datas (ideal para prazos de entrega e logística).
