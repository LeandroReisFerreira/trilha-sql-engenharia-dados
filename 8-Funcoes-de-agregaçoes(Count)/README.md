# Módulo 08: Funções de Agregação

Neste módulo, explorei as funções matemáticas e estatísticas do SQL para consolidar grandes volumes de dados brutos e gerar métricas essenciais de desempenho.

### Conceitos Praticados:
- `COUNT`: Contagem total de registros ou linhas em uma tabela.
- `SUM`: Soma de valores numéricos (muito utilizado para cálculo de faturamento acumulado).
- `AVG`: Média aritmética de valores (essencial para descobrir o ticket médio de vendas).
- `MIN` e `MAX`: Identificação rápida dos valores mínimos e máximos dentro de uma coluna (Ex: produto mais caro e mais barato).
