# Módulo 06: Conversão de Dados

Neste módulo, explorei como modificar o tipo de dado de uma coluna durante a consulta para garantir a compatibilidade em operações matemáticas e de texto.

### Conceitos Praticados:
- Uso de funções de conversão como `CAST` ou equivalentes do banco de dados (ex: converter texto para número ou vice-versa).
- Conversão de strings que contêm números em valores numéricos reais para permitir cálculos de soma ou média.
- Tratamento e formatação de dados brutos para exibição adequada em relatórios.
