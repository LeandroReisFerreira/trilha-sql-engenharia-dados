# Módulo 07: Condicionais

Neste módulo, aprendi a aplicar lógica condicional diretamente nas consultas SQL para categorizar, transformar e rotular dados dinamicamente de acordo com as regras de negócio.

### Conceitos Praticados:
- Estrutura `CASE WHEN` (o equivalente ao "Se / Senão" no SQL) para criar colunas calculadas.
- Criação de faixas de classificação e agrupamentos personalizados (Ex: Classificar produtos em 'Caro' ou 'Barato' com base no preço).
- Personalização de labels e tratamento de dados para tornar relatórios mais claros para o usuário final.
